# EX21 — EX早特21購入支援PWA

React / Viteで構築した非公式の購入支援ツールです。予約・購入確定は公式サイトで手動で行います。

## 機能

- 乗車日・出発駅・到着駅を端末に保存
- 日本時間の21日前23:30を表示
- 購入確認用のカレンダーファイル（締切日22:00・1時間前アラーム）
- 公式予約サイトへのリンク、購入済みの自己申告
- ホーム画面への追加、初回読み込み後のオフライン利用

### v0.2 予約準備機能

- よく使う区間の登録・選択・削除、区間の入れ替え
- 通常発売開始日時（1か月前10:00）と毎秒カウントダウン。前月同日がなければ乗車月1日
- 列車名・号数の指定、または出発／到着の希望時間帯を検索条件として保存
- おとな／こども合計1〜6名、座席・並び席・荷物・全員分の予算・代替候補・メモ
- 入力途中の下書き保存、予定の編集、購入前チェックリスト
- 予約条件のコピーとエクスプレス予約公式サイトへの移動
- 旧版の保存済み予定を自動移行（元データも保持）

検索条件の保存のみで、公式サイト内の検索・自動入力・ボタン操作は行いません。
端末時計に基づく通常発売日の目安です。特別な発売日の変更は公式サイトを優先してください。
条件を編集するとチェックリストは未確認に戻ります。
日付計算の根拠：https://expy.jp/product/hayatoku21/ 、https://www.jreast.co.jp/kippu/02.html

発売期間・除外日・区間・席数・価格を判定しません。期限内でも購入できるとは限りません。
条件は https://www.smart-ex.jp/product/hayatoku21/ で確認してください。
アプリからのプッシュ通知、自動ログイン、自動予約・自動購入はありません。
保存はブラウザーごとで、端末間の同期や復元はありません。

## 開発

### v0.3 発売直前モード・手動操作支援

予定カードの「発売直前モードを開く」から利用します。

- 公開元HTTPサーバーのDateヘッダーによる参考時刻補正。3回取得して最小往復時間のサンプルを使用。古いキャッシュ・2秒超の通信を拒否。5分で失効し、非表示からの復帰時も解除
- 5分・1分・10秒前・開始時刻の画面アラート。音は明示的に有効化して開始。終了・ロック・バックグラウンドでの通知は保証しない
- Wake Lockに対応する環境では表示中のスリープを抑制。失敗・解除を表示し、画面復帰時に再取得。モード終了時に解放
- 実際の予約に影響しない75秒リハーサルと音テスト
- 共通の準備チェック、項目別コピー、公式ログイン・予約条件設定・簡単ログインへのリンク
- ログイン／検索条件／列車・商品・座席／購入確認の手動計測。最終購入操作は行わない

HTTPサーバー補正はNTP同期ではなく、公式予約サーバーとの誤差も分かりません。
時計や通信、OS制限による遅れを避けるための参考情報であり、発売時刻や購入成功は保証しません。
調査根拠は公式公開ガイド。会員のログイン後の実画面での計測は未実施です。
https://expy.jp/reservation/reserve_exic/
https://expy.jp/reservation/useful/menu/
https://expy.jp/reservation/useful/access/

Node.js 22.12以上。`npm ci` → `npm test` → `npm run build`。
開発用は `npm run dev`、ビルド確認は `npm run preview`。

## GitHub Pages

1. Settings → Pages → Source を **GitHub Actions** にする。
2. mainにコミットすると `.github/workflows/deploy.yml` がテスト・ビルド・公開する。
3. Actionsの成功後 https://itukisan-dotcom.github.io/ex21-pwa/ を開く。
4. iPhoneのSafariで共有 → ホーム画面に追加。

Viteのbaseは `/ex21-pwa/`。リポジトリ名変更時は変更してください。
サービスワーカーを変更するときは `public/sw.js` のキャッシュ名も更新してください。
